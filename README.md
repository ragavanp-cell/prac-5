# TrainSphere — Corporate Training & Workshops Website

A responsive web portal built with **CSS Flexbox navigation architecture** (`display: flex`, `flex-direction`, `justify-content`, `align-items`, and `flex-wrap`), featuring the dark navigation bar with **Blog** and **Plans** (`Freelancer`, `Startup`, `Enterprise`) dropdowns, interactive workshop ROI calculator, and authentication modals.

## Unique File Names
- `index.html` — Root entry point for GitHub Pages and Vercel
- `trainsphere-flexbox-ui.css` — Custom CSS Flexbox navigation & corporate training styles
- `trainsphere-workshop-logic.js` — Interactive dropdowns, budget estimator, and modal controllers
- `vercel.json` — Vercel static site configuration

## Deploy to GitHub & Vercel
1. Create a new GitHub repository (e.g., `trainsphere-corporate-training`).
2. Upload all files to the root of your repository.
3. Import the repository in [Vercel](https://vercel.com) and click **Deploy**.
